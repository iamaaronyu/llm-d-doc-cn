# 工作负载

工作负载指南提供在 llm-d 上运行生产工作负载的推荐整体部署方案。每份指南都会先定义工作负载，再把相关的[能力构件](../foundations/README.md)组合成一套针对该负载调优的技术栈。

成熟路径讲解的是单项功能，而工作负载指南从使用场景出发，交付最适合该场景的横向部署方案。

- **[智能体服务](agentic-serving.md)**：长时间、多轮、使用工具的智能体程序（例如编码智能体）——为智能体工作负载组合前缀感知路由、KV 缓存卸载和 P/D 分离。
- **[多模态服务](multimodal-serving.md)**：图像 / 音频 / 视频工作负载——前缀感知与负载感知路由，在聚合式和分离式服务中追踪并匹配多模态载荷。
- **[批处理服务](batch-serving/README.md)**：大规模离线或异步任务——兼容 OpenAI 的批处理网关以及轻量级异步队列处理器。
